## 準備
cd [ディレクトリ（フォルダのパス）] ... カレントディレクトリの確認<br>
git init ... ローカルリポジトリの作成
git branch ... 存在するブランチを確認<br>
git branch [ブランチ名] ... 新規でブランチを作成<br>
git switch [ブランチ名] ... ブランチの切り替え<br>

## 基本コマンド
git add [ファイル名] ... ステージングエリアに登録 ※1<br>
git commit -m "[タイトル]" ... ローカルリポジトリに登録<br>
git push origin [ブランチ名] ... ローカルリポジトリからリモートリポジトリに登録<br>
git pull origin [ブランチ名] ... リモートリポジトリからローカルリポジトリに持ってくる ※2<br>
git log ... コミットの履歴を確認<br>
git status ... 現在の状況確認（何かあればこれでチェック）<br>

## 注意（※のところ）
※1 ... ファイル名のところは -A や . でも対応可能。（全てのファイルをステージングエリアに登録する）<br>
※2 ... 必ずブランチを合わせること 例）main（リモート）ブランチをpullしたい場合は必ずswitchでmainにしてから実行すること(満たしていなければエラーになる)<br>

## 流れ
1. git add [ファイル名]（ステージングエリアに登録）<br>
2. git commit -m "[タイトル]"（タイトルを決め、ローカルリポジトリに登録）<br>
3. git push origin [ブランチ名]（ローカルリポジトリからリモートリポジトリに登録）<br>
4. Githubでプルリクエストを送信し、相方が認証を行い、マージを実行する<br>
5. マージが完了したら、相方のみ git pull origin [ブランチ名] を行うこと<br>

## 知識
ディレクトリ = フォルダ<br>
ブランチ = 世界線のこと<br>

リモートリポジトリ = Githubに保存している<br>
