## 準備
cd [ディレクトリ（フォルダのパス）] ... カレントディレクトリの確認. 
git init ... ローカルリポジトリの作成. 
git branch ... 存在するブランチを確認. 
git branch [ブランチ名] ... 新規でブランチを作成. 
git switch [ブランチ名] ... ブランチの切り替え. 

## 基本コマンド
git add [ファイル名] ... ステージングエリアに登録 ※1. 
git commit -m "[タイトル]" ... ローカルリポジトリに登録. 
git push origin [ブランチ名] ... ローカルリポジトリからリモートリポジトリに登録. 
git pull origin [ブランチ名] ... リモートリポジトリからローカルリポジトリに持ってくる ※2. 
git log ... コミットの履歴を確認
git status ... 現在の状況確認（何かあればこれでチェック）

## 注意（※のところ）
※1 ... ファイル名のところは -A や . でも対応可能。（全てのファイルをステージングエリアに登録する）. 
※2 ... 必ずブランチを合わせること 例）main（リモート）ブランチをpullしたい場合は必ずswitchでmainにしてから実行すること(満たしていなければエラーになる). 

## 流れ
1. git add [ファイル名]（ステージングエリアに登録）. 
2. git commit -m "[タイトル]"（タイトルを決め、ローカルリポジトリに登録）. 
3. git push origin [ブランチ名]（ローカルリポジトリからリモートリポジトリに登録）. 
4. Githubでプルリクエストを送信し、相方が認証を行い、マージを実行する. 
5. マージが完了したら、相方のみ git pull origin [ブランチ名] を行うこと.

## 知識
ディレクトリ = フォルダ. 
ブランチ = 世界線のこと. 
ステージングエリア = ローカルリポジトリに登録する対象を置く場所. 
ローカルリポジトリ = PCの中に保存している. 
リモートリポジトリ = Githubに保存している.
